# Simple Interest Calculator

## Overview
This project contains a Bash script that calculates simple interest based on the principal amount, annual interest rate, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## How to Use
1. Run the `simple-interest.sh` script in a Bash-compatible terminal.
2. Enter the principal amount.
3. Enter the annual interest rate as a percentage.
4. Enter the time period in years.
5. The script calculates and displays the simple interest.
